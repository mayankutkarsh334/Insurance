# 🧱 How to structure the parents' cover

The **plan** is settled — [ABHI Activ One MAX + Chronic Care](README.md), one policy per parent. What remains is the **structure**: how much cover, at what premium, with what complexity. Four approaches.

All four assume ABHI Activ One MAX + Chronic Care, so **day-1 chronic coverage is identical across A/B/C** — 3 of the 4 conditions (BP, diabetes, cholesterol) covered day 1; fatty liver waits (reducible via add-on).

---

## The four approaches

| | Structure | Effective cover / parent | Premium | Coordination | Verdict |
|---|---|---|---|---|---|
| **A** | ₹50L single base each | ₹50L | ₹₹₹ | None — one policy | ⭐ **Best if budget is no constraint** |
| **B** | ₹10L base + ₹40L super top-up each | ~₹50L | ₹₹ | Two clocks to align | ⭐ **Best if optimizing cost** |
| **C** | ₹10L base only each | ₹10L | ₹ | None | Floor, not a safe ceiling |
| **D** | ₹25L **shared** parents floater | ₹25L shared | ₹₹ | Priced on father (60) | ⚠️ Weakest — avoid |

---

## Why base + top-up (B) is cheaper

Senior premiums scale **steeply** with sum insured. A **super top-up only pays after a deductible (₹10L) is crossed**, so the insurer carries only the rare catastrophic year — making that ₹40L layer far cheaper per lakh. Most claims (a diabetes admission, a stent, gallbladder surgery) land **under ₹10L and are fully paid by the base anyway**; the top-up exists to catch the ₹15–40L events (major cardiac, cancer, transplant). Super top-ups are **aggregate-deductible** — the ₹10L is met across all claims in the year, then the top-up pays multiple times.

**Cautions for B, sharpened by the PEDs:**
1. **The top-up has its own waiting periods** — buy **both layers same insurer, same day** so the clocks run in parallel.
2. **Day-1 chronic lives on the base, not automatically on the top-up** — a large diabetes-complication claim spilling past ₹10L may face the top-up's PED wait. Confirm in writing.
3. **The ₹10L base must be renewed every year** — it fills the first ₹10L the top-up never touches.

## Why single base (A) can be worth the extra

For two lives with **four declared conditions**, A buys **simplicity**: one waiting clock, day-1 chronic across the full ₹50L, zero coordination risk. That reduced ambiguity is worth real money when claim probability is high.

## Does restore/refill rescue the shared floater (D)?

A fair challenge — ABHI's **Super Reload** is unlimited. It helps **one** version of the problem but not the others:

| Scenario | Does restore help? |
|---|---|
| **Sequential claims** — father claims ₹25L → pool refills → mother claims later same year | ✅ **Yes** — this is exactly what restore is for |
| **One claim > SI** — a single ₹30L hospitalisation on a ₹25L floater | ❌ **No** — per-claim ceiling is base + bonus, not base + restore; and Super Reload triggers **from the 2nd claim**, so the first big claim can't lean on it |
| **Simultaneous admissions** — both parents hospitalised in the same window (common for elderly couples) | ❌ **Weak** — the two claims compete for one pool before restore cleanly resets |
| **Same-illness recurrence** — father's recurring cardiac events | ⚠️ **Depends** — refill may be limited to *unrelated* illness; must read the wording |

**Deciding point:** even where restore works perfectly, **two individual policies give each parent their own full SI *and* their own restore** — strictly more total protection than one shared SI with one restore engine. Restore raises a floater's resilience; it does not make ₹25L shared equal to ₹50L + ₹50L separate. And the floater is still priced on the father's age. → **Separate policies win.**

> ⏳ Verify in the wording before relying on Super Reload: (a) does it cover the **same illness**, and (b) the exact **2nd-claim trigger** mechanics.

## Recommendation

> **Structure B (₹10L base + ₹40L top-up per parent) if cost-conscious; Structure A (₹50L base each) if premium isn't the deciding factor.** Either delivers ~₹50L per parent — the amount a serious cardiac or cancer episode actually costs. **Not** a shared floater; **not** ₹10L-only.

**Buy now.** With four declared PEDs, the waiting periods and the 5-year moratorium *are* the whole game, and the father (60) is near the fresh-entry age ceiling. Lock in the youngest ages and start every clock today.
